**MyAnimeList（MAL）是真·长期现象级服务，不是炒作。** 它是全球动画/漫画粉丝圈默认的标准数据库与「身份/评分」参照系，但出了这个圈层普通人基本不知道它。双轴评级我给 **`Bg`**——目标人群（全球动漫粉丝）顶流 + 全球特征显著。

---

## 1. 它是什么

- **类型**：动画/漫画数据库 + 社交编目网站（社交目录型服务），2004 年 11 月由**美国人 Garrett Gyssler** 个人创立，原名 AnimeList，蹭 Myspace 潮流改名 MyAnimeList，**英文站**。
- **主战场**：国际（海外）动漫粉丝，尤其是英语圈；日文 UI 一直没做全（2021 年日媒还提到"目前仅英文对应"）。
- **现状归属**：2008 卖 CraveOnline → 2015 被日本 DeNA 收购 → 2019 转手日本电子书公司 **Media Do**；2021 年讲谈社/集英社/小学馆/角川/DMM/博会等日本出版与传媒巨头入股；**2025 年 5 月东京 Web3/AI 公司 Gaudiy（索尼、万代南梦宫系背景）收购 Media Do 持股**。

> 这是个"日本资本控股、但服务全球（非日本）粉丝"的典型案例，本身不是假洋牌，也不靠"自称很火"的话术——它的热度是有机长出来的。

## 3. 跨国 / 全球差异

- **不是"日本出身、日本最火"**：创始人美国、英文优先，控股虽在日本，但**主用户群在海外**（仅美国就约三成，其余全球分散）。典型"跨国倒挂"变体——日本公司、服务全球粉丝。
- **真全球**：230+ 国家覆盖、没有任何单一国家独占，且是业界公认的"MAL Score"评分锚点（工作室/发行方拿它当 KPI）。全球特征**显著** → 挂 `g`。
- **两个真实风险点**：① 中国大陆与俄罗斯被封锁，硬流失两块市场；② 年轻用户流向 AniList（更现代 UI、API 友好、16–24 岁参与度更高），MAL 自身增长仅 ~3% vs 竞品 ~18%。

## 4. 品牌出身拆解

- **真实出身**：美国个人项目（2004）→ 美国 Evolve/CraveOnline（2008）→ 日本 DeNA（2015）→ 日本 Media Do（2019）→ **Gaudiy（2025，东京）** 现为关键股东，叠加讲谈社/集英社/小学馆/角川等日本出版巨头。
- **"自称国外很火"话术？不成立**：它无需包装——21 年沉淀、全球最大动漫数据库（约 2.6 万动画 / 6.8 万漫画条目）、SEO 自然霸榜，靠"有人主动搜、有人直接来"而非买热搜。
- **与竞品定位**：MAL ≈ 完整度+历史库+业界评分权威；AniList ≈ 年轻化+现代 UI；Kitsu ≈ 小众。MAL 在"专门追番平台"里份额约 65%（商业分析口径，部分验证），网站是绝对主入口，官方 App 仅 ~430 万安装、评分 3.47★（偏弱，大家更爱用网页）。

## 5. 可信度结论

**真流行，非炒作。** 四条交叉验证全过：

1. **跨平台**：网站+App+论坛+被 Crunchyroll/Netflix/B 站用户当评分参照，多平台自然出现。
2. **UGC 比例**：海量用户自发打分、写评、建清单、季番讨论，非营销号矩阵。
3. **持续性**：21 年长尾，非尖峰断崖。
4. **消费证据**：真实注册用户（2021 日媒披露约 1800 万 MAU）、真实月访问数千万、广告+订阅+电商多元变现。

**双轴评级：`Bg`**
- 轴一·热度量级：**B 级**——目标人群（全球动漫粉丝）朝圣/默认使用/身份标识，非目标人群基本不参与。
- 轴二·全球属性：**g**——覆盖 230+ 国家、无单一国家主导、全球评分锚点，全球特征显著。
- 量级估算（不编精确数）：月活估在千万级、月访问数千万级，是圈内顶流但远未到"国民人人皆知"（非 S/A）。

> 注意：部分商业 SWOT/BCG 模板站称"6500 万 MAU、年收入 3800 万美元"等，属付费报告口径、偏乐观，我未采信；采用可交叉验证的流量估算与 MAL 自家论坛引用的 SimilarWeb 数据。

{{< bubble >}}所以这相当于是一个动漫型的imdb？{{< /bubble >}}

对，这个类比**在结构上是准的**——但要补一句关键限定：**MAL 是"动漫圈内的 IMDb"，不是"全民版 IMDb"**。

## 像在哪（结构同构）

| 维度 | IMDb（电影/剧） | MAL（动画/漫画） |
|---|---|---|
| 角色 | 领域**最全数据库 + 评分锚点** | 同左，且"MAL Score"被工作室/发行方当 KPI |
| 来源 | 群众外包 + 编辑 | 群众外包 + 志愿者 |
| 流量性质 | 自然搜索 + 直接访问为主，SEO 霸榜 | 同左，付费几乎为 0 |
| 变现 | 广告 + 会员（IMDb Pro）+ 导流 | 广告 + MAL+ 订阅 + 漫画电商/ affiliate |
| 出身 | 个人项目起家，后被大资本收 | 个人项目起家（美国佬 2004），后被日本资本收 |

一句话：**都是"那个领域里所有人默认先去查、引用、打分之地"**。

## 不像在哪（关键差异，也就是我为什么给它 `Bg` 而不是 IMDb 级别的 `Ag/Sg`）

1. **覆盖广度**：IMDb 是**全民级**——不看电影的人也知道、也会查分数；MAL 锁死在**动漫/漫画粉丝**里，圈外人基本没听过。这就是"目标人群顶流 vs 出圈"的区别。
2. **数据类型**：IMDb 含大量专业资料（演职员、票房、制作），公众+行业双用；MAL 更偏**社交编目**（清单、打分、季番表），社区属性重。
3. **竞品格局**：IMDb 在电影库几乎无对手；MAL 有 AniList / Anime-Planet / AniDB 分食，且年轻用户正流向 AniList。
4. **可达性**：IMDb 全球随便开；MAL 在中国大陆和俄罗斯被墙，硬丢两块市场。

## 所以怎么理解最准

> **MAL ≈ 动漫/漫画领域的 IMDb，但影响力半径只在这个圈层内。** 在动漫粉丝眼里它就是"那个标准"，放全球大众尺度上它只是 `Bg`，而 IMDb 是 `Ag` 往上。

如果你要做内容/选题判断：拿 MAL 当"某部动画在核心粉里口碑如何"的硬指标是靠谱的；但别拿它当量级——它证明不了出圈。

需要的话，我可以顺手把 **Bangumi（番组计划）** 拉出来对比——它是中国大陆粉丝圈更常用的"类 IMDb"替代品，正好补齐 MAL 在大陆被墙后那块空白。
